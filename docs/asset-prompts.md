# AetherPet 素材产出示意词（即梦 / JIMENG 用）

> 目标：用统一风格产出 MVP 全套 UI 素材，放入素材包目录 `assets/theme-default/`。
> 即梦产出后可按本文档命名规范存放，前端直接引用。

---

## 0. 全局风格基准词（每张图都要带上）

```
低饱和水彩手绘插画，米黄旧纸张质感，暖色调，细腻柔和的笔触，
朴素温暖的乡下小屋氛围，无文字，无边框，无签名，干净构图
```

**统一负面词**：`文字，水印，签名，边框，复杂细节，高饱和，赛博，3D渲染，照片写实`

**关键技巧（确保成套）**：
- 始终用同一组风格词开头，只更换主体描述
- 色板固定：米黄 `#F2E8D5` / 苔绿 `#8A9B6E` / 陶土 `#C98A5E` / 雾蓝 `#A8BFC7`
- 输出后检查：主体居中、留白充足（供 UI 叠加文案）

## 1. 家的背景图（主场景，横幅大图）

**用途**：登录后的主视角，pet 的家，投喂互动发生在这里。

**比例**：16:9（网页主场景） / 也产出 4:3 备用

**示意词**：
```
低饱和水彩手绘插画，米黄旧纸张质感，暖色调，细腻柔和的笔触，
朴素温暖的乡下小屋室内：靠窗一张原木小桌，桌上放着透明玻璃罐和小碗，
墙角一张铺着格子毯的小床，窗外是模糊的绿野与天空，
阳光从窗户斜斜照进来，地板上有一点落叶，
干净构图，主体居中，留白充足，无文字
```

**变体**：2 张（光照不同：早晨 / 黄昏），供状态切换用。

## 2. 信纸背景（回信专用，竖幅）

**用途**：pet 回信的背景纸，文案叠加其上。

**比例**：3:4（竖版信纸）

**示意词**：
```
低饱和水彩手绘插画，米黄旧纸张质感，暖色调，细腻柔和的笔触，
一张摊开的素色信纸，信纸边缘有柔和水彩晕染和淡淡的花草点缀，
左上角有一枚小小的干花或叶脉压花，右上角留白供放称谓，
底部有浅浅的横线纹理，整体干净素雅，无文字
```

**变体**：3 张（素白 / 带淡苔绿描边 / 带陶土色点缀），供随机使用。

## 4. 奖励物品池（透明底 PNG，小尺寸）

> 用途：用户当天首次登录后，系统从物品池中随机奖励一件，出现在用户物品栏；用户可将其放在桌上送给 pet（即梦的产出即物品视觉素材）。**需要成套小图标，风格统一。**

| 素材 | 示意词补丁（接在风格词后） |
|------|----------------------------|
| 浆果 | 一小串红润的野浆果，带着一小片绿叶，纯白背景，居中 |
| 枯叶 | 一片金黄的枯叶，脉络清晰，边缘微微卷曲，纯白背景，居中 |
| 石子 | 一颗圆润的灰褐色小石子，带着淡淡光泽，纯白背景，居中 |
| 蒲公英 | 一朵蒲公英绒球，几缕绒毛飘起，纯白背景，居中 |
| 松果 | 一颗棕色的松果，鳞片分明，纯白背景，居中 |
| 露珠草叶 | 一片草叶上挂着两滴露珠，清新，纯白背景，居中 |

> 6 种即可，物品池是「随机奖励」机制，越多越好，后续可补。

## 5. pet 状态图（透明底 PNG）

> 用途：主场景里的 pet 形象，3 种状态。**同一只 pet 要保持形象一致**——建议先产出「形象设定图」，再让即梦以图生图的方式生成各状态（保持同一造型）。

### 5.0 形象设定图（基准，最重要）
```
低饱和水彩手绘插画，米黄旧纸张质感，暖色调，细腻柔和的笔触，
一只圆滚滚的小树懒（或你选定的动物），毛色米黄带苔绿花纹，
眼睛圆圆的很温柔，抱着一小段树枝睡觉的姿势，表情平和治愈，
侧面全身，纯白背景，居中，无文字
```

### 5.1 在家状态
```
（以 5.0 形象设定图为参考图）同一只圆滚滚的小树懒，
盘在窗台软垫上打盹，眼睛半睁，身边有一杯热茶，
纯白背景，居中，无文字
```

### 5.2 出门/散步状态
```
（以 5.0 形象设定图为参考图）同一只圆滚滚的小树懒，
背着一个小小的叶子背包，走在乡间小路上，脚步轻快，
纯白背景，居中，无文字
```

### 5.3 旅行中状态
```
（以 5.0 形象设定图为参考图）同一只圆滚滚的小树懒，
坐在田埂或石桥上望着远方的山与云，背影或侧影，带着远行感，
纯白背景，居中，无文字
```

## 7. 即梦使用小贴士

1. **图生图保形象一致**：pet 各状态务必先用 5.0 基准图做参考图，再让它「保持这只小树懒，动作改成…」
2. **一次多出变体**：同一句示意词可多跑几次选最顺眼的
3. **抠图技巧**：即梦若不能直接出透明底，选「纯白背景」产出后在修图工具里去底（白底去底最干净）
4. **尺寸建议**：背景类 1024+；小物类 256–512 即可；pet 类 512–1024
