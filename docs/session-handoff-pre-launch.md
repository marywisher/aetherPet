# 会话交接 — 发布前最小内容包（默认 pet 形象 + 克制级新手引导）

> 本文档是下一个开发会话的启动指令。先读 `docs/current-stage.md` 确认阶段 6 状态，再执行本文件。
> 背景会话结论：竞对 Froggy Roams（Steam，AI 版旅行青蛙，Coming soon）刚上架，本项目的差异化叙事是「开源 + 自托管 + 不把你的聊天喂给第三方 AI 服务」，发布时机要抢在它上线之前。

## 一、已定决策（本会话敲定，下会话直接执行，不再讨论）

### 1. 默认 pet 形象：小刺猬
- 官方默认素材包（`assets/theme-default/`）的 pet 本体定为**小刺猬**
- 理由：
  - 自然系小物，与既有事件文案（看水/数叶子/蒲公英/枯叶/浆果）气质自洽
  - 避开猫/狗赛道（猫咪后院/狗狗后院），不与现有 IP 正面撞车
  - 保留「旅行青蛙关服后」的情怀认知杠杆，但形象本身不侵权（刺猬非该 IP 形象）
- 物种 = 素材包内容（架构决议不变）：未来其他服务中心可分发其他物种素材包，MVP 只锁默认包
- **落点**：`CONTEXT.md` 术语表补一句「默认素材包 pet 形象 = 小刺猬」；`asset-prompts.md` 补小刺猬本体出图词

### 2. 新手引导 = 克制级（红线：不做教程 UI，不出现步骤/任务/打卡字样）
只做三件事，全部走事件引擎 + 素材包插槽，不新增引导系统：

| # | 内容 | 实现形态 |
|---|------|---------|
| ① | **初见事件** `first_meeting`：创建账号首开首页，小刺猬已坐在桌上，摊着一张字条（开场信 1 条文案） | 事件枚举新增 `first_meeting`，仅触发 1 次（pet 创建时） |
| ② | **唯一操作暗示**：首页仅一条浅灰小字「可以把东西放桌上给我」（指向每日馈赠，物品栏空态时同样显示） | 素材包文案插槽，非 UI 组件教程 |
| ③ | **首会话收尾句**：用户首次打开、会话结束时（如点击退出登录/页面卸载前的最后可见位置），显示一句话：**「下次回来的时候，{pet_name}会给你带礼物哦」**——用 pet 命名占位符，预告馈赠/回信闭环 | 1 条固定文案 + pet 名字变量，仅在首会话出现 1 次 |

约束（对齐既有产品纪律）：
- 三处文案全部归入素材包文案文件，事件引擎只认事件结构，不硬编码
- 收尾句的「礼物」语义 = 每日首次登录奖励 + 24h 内回信，不得暗示签到/打卡
- 出现次数各 1 次，之后不再出现（无重复引导）
