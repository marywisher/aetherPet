# 为什么 AetherPet 选择「数据归你、可迁移」？

旅行青蛙的故事提醒我们一件朴素的事：**美好的记忆，不应该跟着 APP 一起消失。** 停服的那一刻，留下的不只是怀念，还有一堆普通用户打不开、也拿不走的档案。

所以 AetherPet 的设计，从第一天就从一个信念出发：**你的宠物，和它记下的每一件事，属于你，不属于任何一家厂商。**

这不是口号，而是落到每一个具体功能里的选择：

- **随时导出**——一键生成 JSON 完整备份：时间线、物品、馈赠记录，一份文件装下全部记忆；
- **随时恢复**——换了机器、数据误删，导入备份就能接上之前的日子；
- **可以自托管**——哪怕只有一台普通服务器，跟着 [`docs/SELF_HOST.md`](SELF_HOST.md) 的傻瓜级教程，就能把整套服务跑在自己手里；
- **可以换中心续玩**——你的数据不绑定 AetherPet 官方服务中心，想去哪去哪；如果官方有一天不再运营，导出数据、换一个服务中心，它依然活着。

也许你会问：那是不是在反对 AI？不是。AI 对话这样的能力，未来会作为**可选插件**接入——用不用、怎么用，由你决定；你的聊天数据不会默认被喂给第三方。数据可迁移和 AI 能力并不矛盾：真正要防的从来不是 AI，而是「记忆被锁死在某家服务器上」。

这些选择并不是后来想起才补的卖点。项目从立项起就是开源的，「数据归用户、资产可迁移」是写进奠基理念的条款，和隐居模式、低频设计一样，是 AetherPet 的性格本身。

数据从一开始就在你手里。停服、迁移、换中心，它都跟着你走。🍃
